## About this example (recorded on daraz.com.bd, 2026-10-30)

How it was made, and what it does *not* do — kept here so nobody mistakes it for more than it is:

- **Search was not used.** Daraz's `robots.txt` disallows `/catalog/` (its search) for automated agents, and Pilot respects that by default. The task therefore started from a product page. A search-based task ("find a wireless mouse…") stops at the first stage with the blocker `robots_disallow`; nothing is picked and nothing is opened. Whether to relax that (`--robots warn`) is the operator's own decision and responsibility.
- **The script ends before the cart.** Pressing *Add to Cart* as a guest opens Daraz's sign-in dialog, so the recorded run stopped with `auth_required` (nothing was paid, ordered or added). To go further, sign in once by hand and reuse the saved session — no password is handed to the tool:

  ```bash
  python agenttrace.py login https://www.daraz.com.bd/ --headed --save daraz-state.json    # log in yourself in the window
  python agenttrace.py pilot "Add this product to the cart and go to the payment page" \
         --url <product page> --state daraz-state.json                                     # stops at the payment page, never pays
  ```

  Keep `daraz-state.json` private: it is a logged-in session.
- **This script was run for real** against the live page: status `success`, exit code 0, title and price read (৳ 975 at the time), the colour option clicked, no payment step. Change `START_URL` to another product page to read its price.
